# Khalid Ahsan — Portfolio

This is the portfolio of Khalid Ahsan, a Product Engineer and Interface Designer.

## Development

You need Node.js and bun — [install bun](https://bun.sh/docs/installation).

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

- TanStack Start
- TypeScript
- React
- Tailwind CSS v4
